# A7 Property Brand System

## Direction

A7 Property uses a clean blue-and-white property discovery language inspired by the clarity and confidence of leading real-estate products, while preserving its own Myanmar-first identity and supplied A7 mark.

## Core palette

- Logo blue: `#1384C8` — supplied A7 mark and large brand text.
- Primary blue: `#0F6FB2` — buttons, selected filters, links, and interactive controls.
- Primary hover: `#0B5F9F` — pressed and hover feedback.
- Cyan accent: `#47BBEA` — highlights, AI moments, and decorative emphasis only.
- Brand navy: `#0B3768` — dashboard navigation, trust surfaces, and high-contrast text.
- Canvas: `#F7F9FC` — page background.
- Surface: `#FFFFFF` — cards, sheets, search controls, and navigation.
- Ink: `#172B3F` — primary content.
- Muted ink: `#4E6478` — secondary content.
- Divider: `#E3EAF1` — borders and separators.
- Success: `#24825F` — verification and confirmed states only.

## Usage rules

- Keep primary screens predominantly white and cool gray; blue communicates action and trust.
- Use cyan sparingly so it remains a distinctive A7 signal.
- Primary controls use the darker accessible blue with white text.
- Verification remains green to distinguish trust status from navigation or selection.
- Property photography stays natural and warm, balancing the cool interface palette.
